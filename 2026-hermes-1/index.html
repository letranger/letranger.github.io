給參加的老師

研習只有一小時，想把時間都留給實際操作，所以請在 10/28（三）以前 照著安裝影片和這份說明，把 Hermes 裝好。 這次研習用 Hermes 來「養龍蝦」：它和最近很紅的龍蝦（OpenClaw）是同一類的 AI Agent，但安裝簡單得多，今天學的東西兩邊都通用。

  • 安裝影片：【影片連結】
  • 整個過程大約 15–20 分鐘，要連網路。
  • 做完請填回報表單：【表單連結】。裝不起來也請回報，當天 9:45 會在教室幫忙處理。

你需要準備

  • 一台筆電，研習當天帶來
    • Mac：要是 Apple 晶片（M1 以後）。Intel 晶片的 Mac 不能裝。 不確定的話，點左上角的蘋果圖示 →「關於這台 Mac」，「晶片」那一欄寫 Apple M 開頭就可以。
    • Windows：Windows 10 或 11
  • 一個 ChatGPT 帳號，用來幫 Hermes 接上模型
  • 一支裝好 Telegram 並且已經登入的手機

一、打開 ChatGPT 的 device code 授權

Hermes 登入 ChatGPT 的方式要用到這個設定，它預設是關閉的，請先把它打開：

  1. 用瀏覽器打開 https://chatgpt.com ，登入你的帳號。
  2. 點左下角的頭像，選 設定/Settings 。
  3. 進入 安全性與登入/Security and login 頁面。
  4. 找到 應用程式安全性/App security 授權的開關，把它打開。開關的名稱可能是英文，例如 啟用 Codex、Excel、PowerPoint 和 Word 的裝置代碼登入/Enable device code sign-in for Codex, Excel, PowerPoint, and Word ，以畫面上的文字為準。

Figure 1: 打開 ChatGPT 的 device code 授權

如果你的 ChatGPT 是學校或單位統一開的工作區帳號，這個開關可能是灰色的或看不到，要請管理員打開，或改用個人帳號。

二、安裝 Hermes

  1. 到官方網站 https://hermes-agent.nousresearch.com/ 下載安裝檔。
    • Mac 下載的是 Hermes-Setup.dmg：打開之後，執行裡面的 Hermes 安裝程式。
    • Windows 下載的是 Hermes-Setup.exe：直接執行。
  2. 安裝程式會自動上網下載需要的元件，大約幾分鐘，等它跑完就好，不用另外安裝其他東西。

Figure 2: 安裝 Hermes

三、登入 ChatGPT

  1. 第一次打開 Hermes 時，畫面會列出可以用的模型提供方，選 ChatGPT or Codex Subscription 。
  2. 畫面上會出現一組驗證碼，照著指示到瀏覽器登入 ChatGPT、輸入驗證碼。
  3. 回到 Hermes，看到對話框就完成了。

如果登入沒有成功

先確認第一步的 device code 授權開關有打開。還是不行的話，打開終端機（Mac 叫「終端機」，Windows 用 PowerShell），輸入： 

hermes model

在清單裡選 ChatGPT or Codex Subscription，畫面上會出現一個網址和一組驗證碼，用瀏覽器打開網址、登入 ChatGPT、輸入驗證碼。

四、檢查兩個設定

打開 Hermes 的「設定」：

  • 安全性（Safety）：維持預設值， 不要改 。這是讓它在做有風險的事之前先問你。
  • 進階（Advanced）：打開「保持電腦喚醒（Keep computer awake）」。電腦睡著時 Hermes 會停下來，打開這個選項，它工作到一半時電腦就不會睡著。

五、下載研習素材

  1. 在你的桌面裡建立一個「研習」資料夾。

    • Mac：回到桌面，在空白的地方按右鍵（觸控板用兩指點按），選「新增檔案夾」，名稱改成「研習」。
    • Windows：回到桌面，在空白的地方按右鍵，選「新增」→「資料夾」，名稱改成「研習」。

    資料夾名稱就是「研習」兩個字，前後不要有空白，也不要放進桌面上的其他資料夾裡。

  2. 下載四個素材檔，放進這個資料夾（在連結上按右鍵，選「另存連結為」）：
    • 段考成績.csv
    • 教學研究會逐字稿.txt
    • 校外教學資訊.md
    • SOUL範本.md

六、確認裝好了

在 Hermes 的對話框輸入： 

請列出桌面上「研習」資料夾裡的所有檔案。

它列出上面四個檔案，就代表安裝、登入、素材都準備好了。

常見問題

我的 Mac 是 Intel 晶片
Hermes 不支援。請改帶 Windows 筆電，或在回報表單裡說明，當天看投影跟著操作。
找不到 device code 授權的開關
如果是學校或單位的工作區帳號，請改用個人帳號。個人帳號也找不到的話，在表單裡回報並附上截圖。
學校的電腦不能裝軟體
請改用自己的筆電，或在表單裡說明，當天看投影跟著操作。
它說找不到「研習」資料夾
確認「研習」資料夾是直接放在桌面上，不是在「文件」或桌面上的其他資料夾裡。 Windows 電腦如果有開 OneDrive 備份，桌面其實在 OneDrive 裡面，可以跟它說「研習資料夾在 OneDrive 的桌面上」。
